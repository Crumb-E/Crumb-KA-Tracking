# Goals
- Read and complete "LearnOpenGL."
- Use Neovim, C, and SDL. As oppossed to C++ and GLFW as used in the book.
- Follow up with a text editor project using the knowledge learnt.

This is a project for skill development. I find completing tutorials with slightly different tools helps prevent mindless instruction following. So in place of C++ and GLFW (Graphics Library Framework), I will use C and SDL (Simple Direct Multimedia Library).

# Weeks 1-2
Selected Neovim as the code editor of choice. Since it's something I want to do and figured it would encourage good practices. Help absorb information better without autocompletion, AI tooling, and such. Also I just think it's neat.

Did prelminary reading on the C language. Hit a small snag. SDL and other low level libraries don't really have a plethora of tutorials. I think this worked out though since reading and understanding the documentation got easier and helped me absorb how the program worked. I believe having to dig into the documentation to understand the windowing and event systems was much more helpful than if I could have just copy-pasted from the book.
